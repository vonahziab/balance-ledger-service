# ADR-0001: Минорные единицы для денег

**Статус:** принято

**Контекст:** ТЗ не указывает тип для `amount`/`balance`.

**Решение:** целые минорные единицы (`bigint`, центы) — и в БД, и в API.
Никакого `numeric`/`float` ни на одном уровне.

**`bigint` на границе JS:** драйвер `pg` отдаёт `bigint` строкой. Денежные
колонки и `balance_ledger.id` получают `ValueTransformer`
(`src/database/bigint.transformer.ts`), который переводит строку в
`number` и падает, если значение больше `Number.MAX_SAFE_INTEGER`. DTO
ограничивает `amount` тем же пределом (≈ 9·10¹⁵ центов — с огромным
запасом).

**Рассмотренные альтернативы:**

- **`numeric(18,2)`** — читаемее в JSON (`100.00`), но требует конвертации
  на границе API и не убирает ошибки округления у клиента с плавающей
  точкой.
- **Строки в API (`"10000"`)** — точнее в теории, но неудобнее клиенту, а
  до предела `number` сервис не доберётся.

**Цена:** `10000` в теле читается хуже, чем `100.00`, — компенсируется
описанием единиц в Swagger и README.
